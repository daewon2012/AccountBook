## 확정 규칙

- API에서 가져온 데이터, 요청 진행과 캐시 무효화는 TanStack Query가 소유한다.
- 메뉴 열림, 일시적 필터와 같은 로컬 UI 상태만 component state를 우선 사용하고 화면 간 공유가 필요할 때 Zustand를 사용한다.
- Axios instance는 base URL, 인증 header와 Problem Details 오류 변환만 담당하며 업무 규칙을 포함하지 않는다.
- GET은 네트워크 오류에 한해 제한적으로 재시도하고 mutation은 멱등성이 보장되지 않으면 자동 재시도하지 않는다.
- 사용자 오류는 field message, 복구 가능한 서버 오류는 toast와 재시도, route 렌더링 오류는 `error.tsx` 경계로 표시한다.
- 폼 입력은 React Hook Form과 Zod schema로 검증하되 서버가 최종 검증 권한을 가진다.
- 테스트마다 독립 QueryClient를 만들고 retry를 끄며 API client와 router를 대체한다.

## 구현 결과

- 앱 셸의 순수 UI 상태는 component state로 격리했다.
- route loading/error 경계와 접근 가능한 재시도 동작을 구현하고 Vitest로 검증했다.
