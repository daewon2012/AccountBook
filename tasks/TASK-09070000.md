# TASK-09070000

## 상태
PLAN

## 목표
개발 및 운영용 reverse proxy 기본 구성을 생성한다.

## 제품 및 버전
- Nginx 1.26+
- Let's Encrypt
- Certbot 2.x

## 계획
1. Nginx 공통 설정과 dev/prod override를 분리한다.
2. 정적 자산과 Web route는 Next.js, /api는 NestJS로 전달한다.
3. X-Forwarded 헤더, request ID, CORS 경계와 upload size를 설정한다.
4. 보안 header, gzip/Brotli, cache 및 rate limit 정책을 적용한다.
5. 운영 TLS certificate 발급·갱신 절차와 HTTP fallback을 문서화한다.

## 산출물
- Nginx route 및 security 설정
- TLS 운영 절차
- 구성 검증 명령

## 검증
- nginx -t가 성공하고 Web/API route가 올바른 upstream으로 전달된다.
- rate limit, cache header, body size와 TLS 갱신 dry-run을 검증한다.

## 실패 및 복구 기준
- 설치나 검증이 실패하면 실패한 단계에서 중단하고 로그를 보존한다.
- 기존 사용자 환경과 데이터를 덮어쓰지 않으며 변경 전 구성으로 되돌릴 수 있게 한다.
