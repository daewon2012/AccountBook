# TASK-00000000

## 상태
DONE

## 목표
시중 가계부 앱을 분석해 공통 기능, 합집합 기능, 앱별 killer 기능을 정리한다.

## 계획
1. 대표 가계부 앱 후보를 선정한다.
2. 앱별 주요 기능을 표 형태로 정리한다.
3. 공통 기능(교집합), 전체 기능(합집합), 앱별 killer 기능을 분리한다.
4. 결과를 다음 작업(TASK-00000001)의 입력으로 정리한다.

## 결과
### 조사 대상 앱
- Money Manager
- Spendee
- YNAB
- Mint
- Wallet by BudgetBakers
- Goodbudget
- Monefy
- Toshl Finance

### 공통 기능 목록
- 수입/지출 거래 등록, 수정, 삭제
- 카테고리 분류
- 월별/주별 내역 조회
- 통계 차트(카테고리/기간 기준)
- 예산 설정 및 사용량 확인
- 반복 거래 등록
- 데이터 백업/복원 또는 동기화
- 통화 설정

### 기능 합집합 목록
- 다중 계좌(현금/카드/은행/전자지갑) 관리
- 자산-부채 추적(대출, 할부, 카드대금)
- 예산 시나리오(월/카테고리/봉투식)
- 목표 기반 저축 트래킹
- 영수증 사진 첨부 및 OCR
- 자동 분류 규칙(키워드/가맹점 기반)
- 거래 위치/태그 기반 분석
- 구독/고정비 모니터링 및 만기 알림
- 가족/파트너 공동 가계부
- 은행/카드 연동(오픈뱅킹 등)
- 다중 통화 및 환율 자동 갱신
- 맞춤형 리포트 및 내보내기(CSV, XLSX, PDF)
- 위젯/빠른 입력
- 지출 알림 및 이상지출 감지
- 오프라인 모드와 충돌 해결 동기화
- 목표 대비 소비 페이스(일평균/주간 burn-rate)
- AI 요약(소비 인사이트, 절약 제안)

### 앱별 killer 기능
- YNAB: 실시간 예산 재배분 중심의 envelope 방식 워크플로우
- Mint: 자동 계좌 연동 기반의 통합 자산 대시보드
- Wallet: 계좌 집계 + 계획 지출 분석의 균형
- Goodbudget: 디지털 봉투 예산 협업 구조
- Spendee: 공동 지갑(Shared Wallet) 협업 경험
- Money Manager: 오프라인 중심의 빠르고 직관적인 입력 UX
- Toshl: 강한 시각화와 다중 통화 친화성
- Monefy: 최소 탭 입력에 특화된 초경량 UX
