## 확정 규칙

- `app/(public)`은 인증 전 화면, `app/(app)`은 앱 셸이 필요한 업무 화면에 사용한다.
- route 파일은 조립만 담당하고 업무별 상태와 UI는 `features/<feature>`에 둔다.
- 재사용 가능한 비업무 UI는 `components/ui`, 앱 전체 layout은 `components/layout`에 둔다.
- `features`는 `app`을 import하지 않으며 공통 UI는 feature를 import하지 않는다.
- 파일은 kebab-case, React component와 type은 PascalCase, hook은 `use` 접두사를 사용한다.
- `@/*`는 `apps/web/src/*`만 가리키며 workspace 간 접근은 package export를 사용한다.

## 구현 결과

- Next.js App Router의 root layout과 `(app)` route group을 생성했다.
- 앱 셸을 `components/layout`에 배치하고 route에서 조립하도록 경계를 적용했다.
- TypeScript `@/*` alias와 Next.js ESLint 구성을 추가했다.
