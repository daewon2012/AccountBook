## 목표
TESTS.md에 정의된 테스트와 정적 검증 도구를 설치하고 기본 test를 생성한다.

## 제품 및 버전
- Vitest 2.x
- Jest 29.x
- Supertest 7.x
- Playwright 1.47+
- ESLint 9.x
- TypeScript 5.6+

## 계획
1. Web/공통은 Vitest, Mobile/API는 Jest runner로 분리한다.
2. API Supertest와 PostgreSQL integration test 환경을 구성한다.
3. Playwright browser 및 root E2E 설정을 설치한다.
4. Web, Mobile, API 각각 성공/실패 smoke unit test를 만든다.
5. 루트 test:unit, test:integration, test:e2e, test:coverage script를 연결한다.

## 산출물
- runner별 설정 파일
- 계층별 smoke test
- 루트 품질 명령

## 검증
- TESTS.md의 실행 명령이 실제 package script와 일치한다.
- lint, typecheck, unit, integration, E2E가 clean 환경에서 성공한다.
- 핵심 모듈 coverage 80% gate가 동작한다.

## 실패 및 복구 기준
- 설치나 검증이 실패하면 실패한 단계에서 중단하고 로그를 보존한다.
- 기존 사용자 환경과 데이터를 덮어쓰지 않으며 변경 전 구성으로 되돌릴 수 있게 한다.
