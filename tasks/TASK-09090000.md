# TASK-09090000

## 상태
PLAN

## 목표
로컬 개발과 운영에 필요한 관측성 기본 서비스를 구성한다.

## 제품 및 버전
- OpenTelemetry JS 1.x
- Prometheus 2.54+
- Grafana 11.x
- Sentry SDK 8.x

## 계획
1. API와 Worker에 OpenTelemetry tracing/metrics 계측을 추가한다.
2. Prometheus scrape 설정과 Grafana datasource를 구성한다.
3. API 지연, 오류율, queue 적체와 DB 연결 dashboard를 만든다.
4. Sentry DSN은 선택적 외부 설정으로 연결하고 환경별 release를 구분한다.
5. 민감정보 redaction과 telemetry 보존 정책을 검증한다.

## 산출물
- 관측성 compose/config
- Grafana dashboard
- Sentry 및 redaction 설정

## 검증
- 한 요청의 correlation ID가 proxy, API와 Worker에서 연결된다.
- metric scrape, dashboard와 의도적 test error 수집이 확인된다.
- secret, token과 개인정보가 telemetry에 없다.

## 실패 및 복구 기준
- 설치나 검증이 실패하면 실패한 단계에서 중단하고 로그를 보존한다.
- 기존 사용자 환경과 데이터를 덮어쓰지 않으며 변경 전 구성으로 되돌릴 수 있게 한다.
