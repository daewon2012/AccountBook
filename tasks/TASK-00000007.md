# TASK-00000007

## 상태
DONE

## 목표
핵심 기능을 분석해 최소한의 가계부 사용 흐름에 필요한 화면과 이동 시나리오를 정의한다.

## 산출물
- [화면 목록](TASK-00000007/screens.md)
- [기본 사용 시나리오](TASK-00000007/scenarios.md)

## 설계 원칙
- 데스크톱과 모바일에서 동일한 정보 구조를 사용한다.
- 주요 행동인 거래 등록은 모든 핵심 화면에서 접근할 수 있다.
- 금액은 수입, 지출, 잔액의 의미가 색상 외에도 부호와 레이블로 구분되게 한다.
- 첫 사용자는 빈 상태 안내를 통해 다음 행동을 이해할 수 있어야 한다.
- 위험한 작업인 삭제와 복원은 확인 단계를 거친다.

## 완료 조건
- 화면 목록과 각 화면의 역할이 문서화되어 있다.
- 기본 사용 흐름과 예외 흐름이 문서화되어 있다.
