# TASK-09040000

## 상태
DONE

## 목표
iOS/Android 모바일 애플리케이션의 기본 source와 실행 구성을 생성한다.

## 제품 및 버전
- React Native
- Expo
- Expo Router
- TanStack Query
- Zustand
- Expo SecureStore

## 계획
1. 공식 Expo TypeScript template로 apps/mobile을 생성한다.
2. React Native와 Expo SDK는 공식 호환 조합을 선택하고 lockfile에 정확히 고정한다.
3. 인증/app route group, tab, modal과 deep link 기본 구조를 만든다.
4. API client, QueryClient, Zustand와 SecureStore Adapter를 연결한다.
5. 기기 API와 환경 설정을 Adapter 뒤에 두고 오프라인 오류 화면을 만든다.

## 산출물
- apps/mobile 실행 가능 source
- Expo Router 기본 구조
- 보안 저장소 및 API Adapter

## 검증
- Expo 개발 서버와 최소 한 개 지원 platform에서 앱이 열린다.
- lint, typecheck와 Jest smoke test가 성공한다.
- 토큰이 일반 AsyncStorage나 로그에 저장되지 않는다.

## 실패 및 복구 기준
- 설치나 검증이 실패하면 실패한 단계에서 중단하고 로그를 보존한다.
- 기존 사용자 환경과 데이터를 덮어쓰지 않으며 변경 전 구성으로 되돌릴 수 있게 한다.
