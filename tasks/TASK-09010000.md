## 상태
PLAN

## 목표
웹, 모바일, API와 공통 패키지를 수용하는 pnpm 모노레포 기본 폴더를 생성한다.

## 제품 및 버전
- pnpm 9.x workspace
- TypeScript 5.6+
- ESLint 9.x
- Prettier 3.x

## 계획
1. package.json, pnpm-workspace.yaml과 공통 ignore/editor 설정을 만든다.
2. apps/web, apps/mobile, apps/api, apps/worker 및 packages 폴더를 만든다.
3. 빈 폴더 보존용 파일 대신 각 workspace manifest와 README를 둔다.
4. 루트 lint, typecheck, test, build 명령을 workspace 재귀 실행으로 연결한다.
5. 환경 파일은 env.dev/env.pub를 직접 복사하지 않고 예시와 검증 schema로 연결한다.

## 산출물
- pnpm workspace root
- apps 및 packages 기본 구조
- 공통 실행 스크립트

## 검증
- pnpm install --frozen-lockfile이 clean checkout에서 성공한다.
- 루트 workspace 조회가 모든 앱과 패키지를 표시한다.

## 실패 및 복구 기준
- 설치나 검증이 실패하면 실패한 단계에서 중단하고 로그를 보존한다.
- 기존 사용자 환경과 데이터를 덮어쓰지 않으며 변경 전 구성으로 되돌릴 수 있게 한다.
