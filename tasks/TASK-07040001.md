2. 시크릿은 1Password Secrets 또는 AWS Secrets Manager로 관리한다.
3. dev/stage/prod 리소스 스펙(CPU/Memory/DB class)을 분리한다.
4. 설정 변경 추적을 GitOps 방식으로 관리한다.

- Terraform 또는 Pulumi

## 확정 정책

- 앱은 시작 시 Zod 기반 schema로 환경변수를 검증하고 누락·형식 오류가 있으면 외부 연결 전에 종료한다.
- 저장소에는 `.env.example`과 변수 설명만 두며 실제 dev/stage/prod secret은 각각 로컬 비추적 파일과 외부 Secret Manager에서 주입한다.
- stage와 prod는 계정, 네트워크, DB, Redis, bucket을 분리하고 production 데이터를 개발 또는 테스트 환경으로 복제하지 않는다.
- dev는 단일 replica와 로컬 Compose를 허용한다. stage는 운영 토폴로지를 축소해 유지하고 prod는 최소 2개 API replica와 관리형 데이터 서비스를 기본값으로 한다.
- CPU, memory와 DB class는 부하 테스트 및 p95 latency를 근거로 조정하며 값 변경은 IaC pull request와 승인 기록으로 추적한다.
- 로그와 진단 출력에서는 password, token, connection string 및 개인 금융 데이터를 마스킹한다.
