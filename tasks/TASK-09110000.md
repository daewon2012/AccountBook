# TASK-09110000

## 상태
PLAN

## 목표
Stage와 Production 서버에 필요한 runtime 및 관리 서비스를 설치한다.

## 제품 및 버전
- Linux
- Docker Engine
- Nginx 1.26+
- PostgreSQL 16.x
- PgBouncer 1.22+
- Redis 7.x
- S3-compatible Storage
- Certbot 2.x

## 계획
1. Architectures.md에 따라 stage/prod host와 managed service 경계를 확정한다.
2. 최소 권한 OS 계정, firewall, patch와 container runtime 정책을 적용한다.
3. Web/API/Worker image 배포와 DB/Redis/Storage 연결을 구성한다.
4. env.pub 값은 외부 secret store에 등록하고 접근 권한을 분리한다.
5. TLS 자동 갱신, DB backup/PITR, 로그 보관과 health monitoring을 구성한다.

## 산출물
- 환경별 설치 자산 목록
- 운영 구성 및 secret mapping
- backup/TLS/patch 운영 절차

## 검증
- 모든 운영 구성요소의 healthcheck와 보안 연결이 통과한다.
- secret이 source, image와 배포 log에 노출되지 않는다.
- backup 생성과 제한된 restore 검증이 성공한다.

## 실패 및 복구 기준
- 설치나 검증이 실패하면 실패한 단계에서 중단하고 로그를 보존한다.
- 기존 사용자 환경과 데이터를 덮어쓰지 않으며 변경 전 구성으로 되돌릴 수 있게 한다.
