# TASK-09100000

## 상태
PLAN

## 목표
모든 로컬 구성요소를 한 번에 실행하고 기본 요청 흐름을 검증한다.

## 제품 및 버전
- Docker Compose
- pnpm 9.x
- Playwright 1.47+

## 계획
1. 의존 service와 app 시작 순서를 하나의 개발 명령으로 묶는다.
2. DB migration, bucket 초기화와 health 대기 절차를 자동화한다.
3. Web에서 Nginx/API/DB까지 이어지는 smoke 시나리오를 실행한다.
4. Queue job과 Object Storage 업로드·조회 smoke 시나리오를 실행한다.
5. start, stop, reset 및 troubleshooting 절차를 문서화한다.

## 산출물
- 통합 개발 실행 명령
- 로컬 smoke test
- 개발환경 runbook

## 검증
- clean checkout에서 문서 절차만으로 환경을 재현한다.
- 재시작, graceful stop과 reset 후 모든 healthcheck가 통과한다.

## 실패 및 복구 기준
- 설치나 검증이 실패하면 실패한 단계에서 중단하고 로그를 보존한다.
- 기존 사용자 환경과 데이터를 덮어쓰지 않으며 변경 전 구성으로 되돌릴 수 있게 한다.
