# 화면 목록

| 화면 ID | 화면 | 목적 | 핵심 구성 |
|---|---|---|---|
| UI-01 | 대시보드 | 현재 재무 상태와 필요한 행동을 한눈에 확인한다. | 이번 달 수입·지출·잔액, 예산 진행률, 최근 거래, 빠른 거래 등록 |
| UI-02 | 거래 목록 | 거래를 검색하고 수정·삭제할 대상을 찾는다. | 기간·유형·카테고리 필터, 거래 목록, 페이지네이션, 빈 상태 |
| UI-03 | 거래 입력 | 수입 또는 지출을 빠르고 정확하게 등록·수정한다. | 유형, 금액, 날짜, 계좌, 카테고리, 메모, 영수증 첨부 |
| UI-04 | 예산 | 월간 예산과 카테고리별 소진 상태를 확인·조정한다. | 월 선택, 전체 사용률, 카테고리 예산, 초과 경고, 예산 편집 |
| UI-05 | 계좌·자산 | 계좌별 잔액과 총자산·부채를 확인한다. | 총자산, 총부채, 순자산, 계좌 목록, 계좌 추가 |
| UI-06 | 리포트 | 기간별 소비 추이와 주요 지출을 분석한다. | 기간 선택, 수입·지출 추이, 카테고리 비중, 이상지출 안내 |
| UI-07 | 설정 | 통화, 백업·복원, 동기화 및 공동 가계부 설정을 관리한다. | 기본 통화, 백업 생성, 복원, 동기화 상태, 멤버 관리 |

## 공통 내비게이션
- 데스크톱: 좌측 사이드바에 대시보드, 거래, 예산, 계좌, 리포트, 설정을 표시한다.
- 모바일: 하단 탭에 대시보드, 거래, 예산, 리포트를 두고 나머지는 더보기에서 제공한다.
- 거래 등록 버튼은 데스크톱 상단과 모바일 플로팅 버튼에 고정한다.
