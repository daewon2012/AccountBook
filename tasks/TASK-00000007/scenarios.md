# 기본 사용 시나리오

## 1. 첫 거래 등록
1. 사용자가 대시보드에서 거래 등록 버튼을 선택한다.
2. 거래 입력 화면에서 지출 유형, 금액, 날짜, 계좌와 카테고리를 입력한다.
3. 저장하면 거래 목록에 추가되고 대시보드·예산·계좌 집계가 갱신된다.
4. 저장 실패 시 입력값을 유지한 채 필드 오류 또는 재시도 안내를 표시한다.

## 2. 거래 조회 및 수정
1. 사용자가 거래 목록으로 이동한다.
2. 기간과 카테고리 필터로 거래를 찾는다.
3. 거래를 선택하여 입력 화면에서 수정한다.
4. 저장 후 이전 필터와 스크롤 위치를 유지한 거래 목록으로 돌아간다.

## 3. 월간 예산 확인
1. 사용자가 대시보드의 예산 진행률을 선택해 예산 화면으로 이동한다.
2. 카테고리별 사용액과 잔여액을 확인한다.
3. 예산 편집 후 저장하면 소진율과 초과 경고가 즉시 다시 계산된다.

## 4. 자산 및 리포트 확인
1. 사용자가 계좌·자산 화면에서 총자산과 계좌별 잔액을 확인한다.
2. 리포트 화면으로 이동해 이번 달 소비 추이와 상위 지출 카테고리를 확인한다.
3. 이상지출 안내를 선택하면 해당 거래로 필터링된 거래 목록으로 이동한다.

## 5. 백업 생성과 복원
1. 사용자가 설정 화면에서 백업 생성을 선택한다.
2. 생성 결과와 생성 시각을 확인하고 파일을 내려받는다.
3. 복원 시 파일 검증 결과와 변경 범위를 먼저 확인한다.
4. 사용자가 최종 확인한 경우에만 복원을 실행하고 실패 시 기존 데이터를 유지한다.

## 화면 이동 요약
```text
대시보드 ─┬─> 거래 목록 ─> 거래 입력 ─> 거래 목록
          ├─> 거래 입력 ─────────────> 대시보드
          ├─> 예산
          ├─> 계좌·자산
          └─> 리포트 ─> 필터된 거래 목록

설정 ─> 백업 생성 / 복원 확인
```
