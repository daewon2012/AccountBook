# 인터페이스 기능 목록

## 웹

### 공통

#### 앱 셸과 반응형 내비게이션

- 데스크톱과 모바일 크기에 맞는 내비게이션을 제공한다.
- 현재 화면, 로딩과 오류 상태를 접근 가능하게 표시한다.

### 대시보드

#### 대시보드

- 월간 요약, 예산 진행률과 최근 거래를 데이터에 연동한다.
- 로딩, 빈 상태와 오류 상태를 제공한다.

### 거래목록

#### 거래 목록

- 기간, 유형과 카테고리 필터를 거래 목록 조회에 연동한다.
- 거래 수정·삭제 진입과 페이지네이션을 제공한다.

### 거래입력

#### 거래 등록과 수정

- 거래 필드 검증과 등록·수정 흐름을 제공한다.
- 저장 실패 시 입력값을 유지하고 오류를 안내한다.

### 예산

#### 월간 예산

- 월 선택, 예산 편집과 소진율 표시를 제공한다.
- 초과 및 잔여 예산 상태를 명확하게 표시한다.

### 계좌자산

#### 계좌와 자산

- 계좌 목록과 자산·부채 집계를 데이터에 연동한다.
- 계좌 추가와 상세 조회 진입을 제공한다.

### 리포트

#### 분석 리포트

- 기간별 소비 추이와 카테고리 순위를 차트에 연동한다.
- 이상 지출에서 필터된 거래 목록으로 이동할 수 있게 한다.

### 설정

#### 설정과 백업·복원

- 설정 조회·변경과 백업 생성 흐름을 제공한다.
- 복원 전에 데이터 검증과 사용자 확인 단계를 제공한다.

## 모바일

### 공통

#### 앱 셸과 하단 내비게이션

- 하단 탭과 거래 등록 플로팅 버튼을 제공한다.
- 기기 안전 영역과 접근성 기준을 적용한다.

### 대시보드

#### 대시보드

- 월간 요약 카드와 최근 거래를 데이터에 연동한다.
- 로딩, 빈 상태와 새로고침을 제공한다.

### 거래목록

#### 거래 목록

- 검색, 필터와 목록 페이지 로딩을 제공한다.
- 선택한 거래의 상세 조회와 수정 흐름을 제공한다.

### 거래입력

#### 거래 등록과 수정

- 모바일 키보드와 스크롤을 고려한 입력 및 검증을 제공한다.
- 영수증 첨부와 저장 실패 복구를 제공한다.

### 예산

#### 월간 예산

- 월 선택, 예산 소진율과 예산 편집을 제공한다.
- 예산 초과 상태를 접근 가능하게 표시한다.

### 계좌자산

#### 계좌와 자산

- 자산·부채 집계와 계좌 목록을 데이터에 연동한다.
- 계좌 추가와 상세 화면 진입을 제공한다.

### 리포트

#### 분석 리포트

- 기간 전환과 소비 차트 데이터를 연동한다.
- 이상 지출에서 관련 거래 목록으로 이동할 수 있게 한다.

### 설정

#### 설정과 백업·복원

- 설정 변경과 백업 생성 흐름을 제공한다.
- 복원 전에 데이터 검증과 사용자 확인 단계를 제공한다.
