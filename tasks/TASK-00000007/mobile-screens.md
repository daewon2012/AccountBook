# 모바일 화면 목록

| 화면 ID | 화면 | 목적 | 모바일 핵심 구성 |
|---|---|---|---|
| M-01 | 대시보드 | 이번 달 재무 상태와 최근 활동을 빠르게 확인한다. | 월간 요약 스와이프 카드, 예산 진행률, 최근 거래, 거래 등록 FAB |
| M-02 | 거래 목록 | 거래를 검색하고 상세·수정 화면으로 이동한다. | 검색, 필터 시트, 날짜별 거래 그룹, 무한 스크롤 |
| M-03 | 거래 입력 | 최소 단계로 수입·지출을 등록하거나 수정한다. | 유형 탭, 숫자 키패드, 날짜·계좌·카테고리, 메모, 영수증 |
| M-04 | 예산 | 월간·카테고리 예산의 소진 상태를 확인한다. | 전체 진행률, 카테고리 카드, 초과 경고, 편집 버튼 |
| M-05 | 계좌·자산 | 순자산과 계좌별 잔액을 확인한다. | 자산 요약, 계좌 그룹, 계좌 추가 |
| M-06 | 리포트 | 소비 추이와 상위 지출 및 이상지출을 확인한다. | 기간 칩, 추이 차트, 카테고리 순위, 인사이트 카드 |
| M-07 | 설정 | 통화, 동기화, 공동 가계부와 백업을 관리한다. | 설정 목록, 동기화 상태, 멤버, 백업·복원 |

## 공통 내비게이션
- 하단 탭: 홈, 거래, 예산, 리포트, 더보기
- 거래 등록: 하단 탭 위 중앙 플로팅 버튼
- 계좌와 설정: 더보기 화면에서 진입
- 상세 화면: 상단 뒤로 가기와 명확한 화면 제목 제공
