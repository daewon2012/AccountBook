# 모바일 기본 사용 시나리오

## 1. 빠른 거래 등록
1. 사용자가 어느 핵심 화면에서든 거래 등록 플로팅 버튼을 누른다.
2. 거래 입력 화면에서 지출·수입 유형과 금액을 먼저 입력한다.
3. 날짜, 계좌와 카테고리를 선택하고 저장한다.
4. 저장 성공 후 이전 화면으로 돌아가 집계를 갱신한다.
5. 실패하면 입력값을 유지하고 재시도 안내를 표시한다.

## 2. 거래 탐색과 수정
1. 하단 거래 탭에서 거래 목록을 연다.
2. 필터 버튼으로 기간·유형·카테고리 바텀시트를 연다.
3. 거래를 선택하여 상세를 확인하고 수정 화면으로 이동한다.
4. 저장 후 필터와 목록 위치를 유지한다.

## 3. 예산 초과 확인
1. 예산 탭에서 초과 카테고리를 선택한다.
2. 해당 카테고리의 사용 내역을 확인한다.
3. 필요하면 예산을 수정하거나 관련 거래 목록으로 이동한다.

## 4. 리포트에서 거래 확인
1. 리포트 탭에서 기간과 소비 추이를 확인한다.
2. 이상지출 카드를 선택한다.
3. 관련 조건이 적용된 거래 목록으로 이동한다.

## 5. 백업과 복원
1. 더보기에서 설정으로 이동한다.
2. 백업을 생성하거나 복원 파일을 선택한다.
3. 복원 영향 범위를 확인한 뒤 최종 승인한다.
4. 실패 시 기존 데이터 유지와 복구 안내를 표시한다.

## 이동 요약
```text
하단 탭: 홈 ↔ 거래 ↔ 예산 ↔ 리포트 ↔ 더보기
              ↑       ↑        ↑
              └── 관련 거래 목록 ──┘
모든 핵심 화면 ─> 거래 등록 ─> 이전 화면
더보기 ─> 계좌·자산 / 설정 ─> 백업·복원
```
