## 단계별 설치 작업
1. 기반 환경 설치
- Windows 기능에서 WSL, 가상화 기능 활성화
- Ubuntu 24.04 LTS 설치
- Docker Desktop 설치 후 WSL 통합 활성화

2. 개발 툴체인 설치
- nvm 또는 fnm 설치 후 Node.js 22 LTS 적용
- corepack enable 후 pnpm 9.x 활성화
- Git, VS Code, 필수 확장(ESLint, Docker, Dev Containers) 설치

3. 프로젝트 템플릿 설치
- Next.js 14 템플릿 생성
- NestJS 10 API 프로젝트 생성
- 공통 TypeScript 및 lint 규칙 통합

4. 데이터/인프라 컨테이너 구성
- docker-compose로 PostgreSQL 16, Redis 7, MinIO, Nginx 구성
- Prisma 초기 마이그레이션 및 시드 실행
- 헬스체크와 볼륨 정책 정의

5. 테스트/품질 파이프라인 구성
- Vitest/Jest, Supertest, Playwright 초기 테스트 추가
- ESLint/Prettier pre-commit 훅 설정
- GitHub Actions에 lint/test 워크플로우 추가

6. 관측성/운영 준비
- OpenTelemetry + Prometheus 메트릭 노출
- Grafana 대시보드 기본 템플릿 추가
- Sentry 에러 트래킹 연동

7. 환경변수 템플릿 준비
