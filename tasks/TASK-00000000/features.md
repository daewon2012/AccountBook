# 기능 목록

기존 `TASK-01*` 계획 문서의 내용을 기능 응집도에 따라 재분류한 목록이다.

## 공통 구현 원칙

- 상태: PLAN
- 각 기능은 요구사항과 완료 조건을 재확인한 뒤 도메인 모델, 유스케이스, 인터페이스를 설계한다.
- 구현 순서와 검증 방법을 정의하고, 아래 완료 조건을 충족한다.
- 괄호 안 ID는 이전 문서의 추적용 ID이며, `의존`은 이전 계획의 선행 관계를 보존한다.

## 거래 관리

### 거래 모델과 저장소 (TASK-01010001)

- 수입/지출, 금액, 일자, 카테고리, 메모를 가진 거래 엔티티를 정의한다.
- 거래 저장소 인터페이스와 기본 구현을 준비한다.
- 의존: 없음

### 거래 단건 관리 (TASK-01010002)

- 거래 등록, 수정, 삭제, 단건 조회를 구현한다.
- 입력 검증과 예외 응답 규칙을 적용한다.
- 의존: TASK-01010001

### 거래 목록 조회 (TASK-01010003)

- 기간과 카테고리 기준 목록 조회를 제공한다.
- 최신순 정렬과 페이지네이션 정책을 정의한다.
- 의존: TASK-01010002

## 반복 거래

### 반복 규칙 (TASK-01010101)

- 반복 주기, 시작일, 종료일, 예외일 규칙을 정의한다.
- 거래 템플릿과 반복 규칙의 연결 구조를 정의한다.
- 의존: TASK-01010001

### 반복 거래 생성 (TASK-01010102)

- 일/주/월 반복 계산으로 거래 초안을 생성한다.
- 중복 생성 방지 키를 적용한다.
- 의존: TASK-01010101, TASK-01010002

### 반복 거래 보정 (TASK-01010103)

- 자동 생성 전후에 사용자가 거래를 보정할 수 있게 한다.
- 건너뛰기와 일회성 수정 정책을 적용한다.
- 의존: TASK-01010102

## 영수증 OCR

### 영수증 첨부 (TASK-01010201)

- 거래에 영수증 이미지를 첨부하고 삭제할 수 있게 한다.
- 파일 메타데이터와 접근 제어를 정의한다.
- 의존: TASK-01010002

### OCR 어댑터 (TASK-01010202)

- OCR 요청 및 응답 DTO를 정의한다.
- 공급자를 교체할 수 있는 어댑터 인터페이스를 제공한다.
- 의존: TASK-01010201

### OCR 결과 확정 (TASK-01010203)

- 금액, 가맹점, 일시 후보를 사용자에게 제시한다.
- 사용자가 확정한 후보를 거래 필드에 안전하게 반영한다.
- 의존: TASK-01010202

## 예산 관리

### 예산 모델 (TASK-01020001)

- 예산 기간, 금액, 카테고리 구조를 정의한다.
- 중복 예산 처리 정책을 정의한다.
- 의존: TASK-01010001

### 월간 예산 관리 (TASK-01020002)

- 월간 예산 생성, 조회, 수정, 삭제를 제공한다.
- 음수와 초과 금액에 대한 유효성 검증을 적용한다.
- 의존: TASK-01020001

### 예산 소진 계산 (TASK-01020003)

- 사용률, 잔여 예산, 초과 금액을 계산한다.
- 거래 변경 시 계산값을 갱신한다.
- 의존: TASK-01020002, TASK-01010003

## 봉투 예산

### 봉투 모델과 배정 (TASK-01020101)

- 봉투 생성, 삭제, 잠금 규칙을 정의한다.
- 월간 배정과 이월 정책을 정의한다.
- 의존: TASK-01020001

### 봉투 간 재배정 (TASK-01020102)

- 봉투 잔액 이동을 원자적으로 처리한다.
- 재배정 이력을 기록한다.
- 의존: TASK-01020101

### 소비 연동 차감 (TASK-01020103)

- 거래 확정 시 해당 봉투의 잔액을 차감한다.
- 잔액 부족 경고 정책을 적용한다.
- 의존: TASK-01020102, TASK-01010002

## 저축 목표

### 저축 목표 모델 (TASK-01020201)

- 목표 금액, 시작일, 마감일, 우선순위를 정의한다.
- 진행, 달성, 중단 상태 전이를 정의한다.
- 의존: TASK-01010001

### 목표 금액 반영 (TASK-01020202)

- 목표별 입금과 차감을 누적 금액에 반영한다.
- 거래 취소와 수정 시 정합성을 유지한다.
- 의존: TASK-01020201, TASK-01010002

### 목표 달성 예측 (TASK-01020203)

- 기간 대비 목표 진척률을 계산한다.
- 현재 저축 속도를 기준으로 예상 달성일을 제공한다.
- 의존: TASK-01020202

## 계좌와 자산

### 계좌 모델 (TASK-01030001)

- 현금, 카드, 은행 계좌 유형을 정의한다.
- 계좌 활성 및 비활성 상태 규칙을 정의한다.
- 의존: TASK-01010001

### 계좌 관리 (TASK-01030002)

- 계좌 등록, 수정, 비활성화를 제공한다.
- 초기 잔액과 잔액 산정 시작일을 관리한다.
- 의존: TASK-01030001

### 총자산 집계 (TASK-01030003)

- 계좌별 잔액과 총자산을 계산한다.
- 거래 반영 시 집계값을 즉시 갱신한다.
- 의존: TASK-01030002, TASK-01010003

## 부채와 할부

### 부채 계약 모델 (TASK-01030101)

- 원금, 이율, 상환 주기, 만기 구조를 정의한다.
- 계약 상태 전이를 정의한다.
- 의존: TASK-01030001

### 상환 일정 계산 (TASK-01030102)

- 월별 원리금 상환 일정을 계산한다.
- 조기 상환과 부분 상환 시 일정을 재계산한다.
- 의존: TASK-01030101

### 상환 현황 조회 (TASK-01030103)

- 월 상환액과 잔여 원금을 조회한다.
- 계좌 잔액과 연결된 결제 반영을 지원한다.
- 의존: TASK-01030102, TASK-01030003

## 자동 분류

### 분류 규칙 DSL (TASK-01040001)

- 키워드, 가맹점, 정규식 규칙 타입을 정의한다.
- 규칙 충돌 시 우선순위 정책을 정의한다.
- 의존: TASK-01010001

### 분류 규칙 관리 (TASK-01040002)

- 규칙 생성, 수정, 비활성화를 제공한다.
- 테스트 입력으로 규칙 적용 결과를 미리 볼 수 있게 한다.
- 의존: TASK-01040001

### 자동 분류 실행 (TASK-01040003)

- 신규 거래 저장 시 분류 규칙을 자동 적용한다.
- 추천 결과의 신뢰도 점수를 제공한다.
- 의존: TASK-01040002, TASK-01010002

## 구독과 알림

### 반복 결제 탐지 (TASK-01040101)

- 금액, 주기, 가맹점 유사도 기준을 정의한다.
- 고정비 후보 점수 기준을 정의한다.
- 의존: TASK-01010102, TASK-01040003

### 구독 항목 관리 (TASK-01040102)

- 구독 항목 확정, 해제, 일시 중지를 제공한다.
- 결제 주기와 예상 금액을 수정할 수 있게 한다.
- 의존: TASK-01040101

### 결제일 알림 (TASK-01040103)

- 만기나 결제일 N일 전에 알림을 발송한다.
- 알림 중복 발송 방지 정책을 적용한다.
- 의존: TASK-01040102

## 외부 계좌 연동

### 연동 어댑터 계약 (TASK-01040201)

- 연동 오류 코드 표준을 정의한다.
- 의존: TASK-01030001

### 동기화 모드 (TASK-01040202)

- 계좌별 수동 또는 자동 동기화 모드를 설정할 수 있게 한다.
- 모드 전환 시 데이터 정합성을 검증한다.
- 의존: TASK-01040201

### 샌드박스 연동 (TASK-01040203)

- 테스트용 가상 거래 데이터를 동기화한다.
- 실패 시 재시도와 백오프 정책을 적용한다.
- 의존: TASK-01040202

## 분석 집계

### 분석 집계 모델 (TASK-01050001)

- 기간, 카테고리, 계좌 기준 집계 스키마를 정의한다.
- 집계 갱신 주기를 정의한다.
- 의존: TASK-01010003, TASK-01030003

### 소비 추이 (TASK-01050002)

- 일, 주, 월 단위 소비 추이 데이터를 제공한다.
- 수입과 지출을 분리하여 집계한다.
- 의존: TASK-01050001

### 지출 순위 (TASK-01050003)

- 기간 내 카테고리별 지출 순위를 제공한다.
- 전체 지출 대비 카테고리 비중을 계산한다.
- 의존: TASK-01050001

## 데이터 내보내기

### 내보내기 계약 (TASK-01050101)

- 필드 선택, 정렬, 필터 옵션 계약을 정의한다.
- 파일명과 문자 인코딩 정책을 정의한다.
- 의존: TASK-01050001

### CSV 내보내기 (TASK-01050102)

- 조회 결과를 CSV 파일로 내보낸다.
- 대용량 데이터의 분할 내보내기 정책을 적용한다.
- 의존: TASK-01050101

### PDF 요약 리포트 (TASK-01050103)

- 총수입, 총지출, 상위 지출 카테고리를 포함한 월간 PDF를 생성한다.
- 템플릿 기반 스타일을 적용한다.
- 의존: TASK-01050101, TASK-01050002, TASK-01050003

### 이상 지출 기준선 (TASK-01050201)

- 분석에 필요한 최소 관측치 기준을 정의한다.
- 의존: TASK-01050001

### 급증 지출 탐지 (TASK-01050202)

- 기준선을 초과한 지출 이벤트를 생성한다.
- 오탐을 줄이기 위한 노이즈 필터링 규칙을 적용한다.
- 의존: TASK-01050201

### 절약 제안 (TASK-01050203)

- 절약 우선순위가 높은 카테고리를 추천한다.

- 의존: TASK-01050202

## 백업과 동기화

### 백업 스키마 (TASK-01060001)

- 거래, 예산, 계좌를 포함하는 백업 스키마를 정의한다.
- 스키마 마이그레이션 버전 정책을 정의한다.
- 의존: TASK-01010001, TASK-01030001

### 로컬 백업과 복원 (TASK-01060002)

- 수동으로 백업을 생성하고 복원할 수 있게 한다.
- 복원 전 검증과 실패 시 롤백 정책을 적용한다.
- 의존: TASK-01060001

### 동기화 충돌 해결 (TASK-01060003)

- last-write-wins와 수동 병합 모드를 지원한다.
- 충돌 로그를 기록한다.
- 의존: TASK-01060002

## 다중 통화

### 통화와 환율 모델 (TASK-01060101)

- 기본 통화, 표시 통화, 거래 통화 구조를 정의한다.
- 환율의 유효 시각과 출처를 기록한다.
- 의존: TASK-01030001

### 환율 갱신 (TASK-01060102)

- 환율을 수동 또는 자동으로 갱신한다.
- 갱신 실패 시 마지막 유효 환율로 대체한다.
- 의존: TASK-01060101

### 통화 환산 (TASK-01060103)

- 통화 환산 후 자산과 리포트 값을 재계산한다.
- 환율 변동의 영향 비교값을 제공한다.
- 의존: TASK-01060102, TASK-01050001
